《星语随心消消乐》隐私政策

更新及生效日期：2026年10月8日 · 离线版本 1.0.1
包名：com.match.xysx.honor

本政策说明兰溪市辰谷信息技术服务有限公司（以下简称“我们”）运营的《星语随心消消乐》离线版本如何处理信息。请在开始游戏前阅读。您可先阅读全文，再选择同意或不同意。

一、当前版本与处理范围

本版本提供本地消除玩法，以游客方式进入，不创建在线账号，不接入荣耀账号、广告、支付或联运服务，不提供在线聊天和云存档。游客进入不等于实名认证，也不创建可跨设备使用的账号。

二、游戏在设备上的信息处理

为运行游戏，游戏引擎在设备上使用系统版本、设备图形与音频能力、屏幕尺寸、语言及游戏运行状态等信息。游戏进度、分数、设置及您对本政策版本的同意状态保存在应用本地存储。处理目的分别为完成游戏绘制和播放、保存游戏状态、记住您的选择；处理方式为在设备本地读取与写入。

本安装包未声明网络访问权限，不主动将上述游戏数据发送至我们的服务器。我们不通过本版本要求您提交姓名、身份证、手机号、通讯录、精确位置、照片或支付信息。设备系统可能自行保留应用运行和崩溃记录，该部分由您使用的操作系统管理。

三、运行组件与信息共享

本游戏包含 Unity 游戏运行时、FMOD 音频运行组件和游戏本地适配代码，用于图形、输入、音频和本地游戏逻辑；当前版本未启用在线分析、广告及账号接口。未接入荣耀账号、联运或支付 SDK。我们不向广告商出售或共享游戏本地数据。

协议全文随安装包提供，断网也可阅读。只有您主动选择“浏览器打开”时，系统才会把对应的公开 GitHub Pages 网页交给浏览器。此时浏览器和 GitHub 可按其各自规则处理访问所需的 IP 地址、请求时间和浏览器信息；这不是游戏后台上传存档。您可继续使用本地全文而不打开浏览器。

四、设备权限

当前版本未声明互联网、相机、麦克风、定位、通讯录或外部存储读取权限，不弹出这些权限申请。本地进度使用应用自己的存储空间。

五、保存期限与安全

本地游戏信息在设备上保留至您清除应用数据或卸载应用；请注意此操作可能永久删除进度，当前无云端恢复服务。同意状态保留至您撤回、清除数据或卸载。我们通过应用私有存储、减少数据处理和关闭不需要的接口保护信息。

如您主动通过邮箱或电话联系我们，我们将处理您提供的联系方式和问题内容，仅用于答复、处理请求及必要的记录留存。请勿主动提供与问题无关的身份证件、密码等敏感信息。处理结束后，我们在实现该目的所需期限内保留记录，之后删除或匿名化；法律另有要求的除外。

六、您的选择与权利

您可在游戏中的“隐私·适龄”入口重新阅读本政策和用户协议；选择“撤回同意并退出”会清除本版本的同意记录并退出游戏，下次启动重新询问，不自动删除存档。要删除全部本地数据，可在系统应用设置中清除本游戏数据。由于没有在线账号，本版本没有在线账号注销流程。

对于您主动向我们提供的信息，您可通过下方联系方式提出查阅、复制、更正、删除、撤回同意或其他个人信息请求。我们会进行必要且适度的身份核验，并通常在十五个工作日内回复；复杂情况会说明处理进度。撤回不影响此前基于同意进行的处理。

七、未成年人

未成年人请在监护人指导下阅读和使用游戏，合理安排时间。本版本不要求提交儿童个人信息，不提供充值或在线社交。监护人如发现向我们误发了儿童个人信息，可联系我们处理。本地游客入口不具备实名认证能力，也不替代发行渠道要求的实名与防沉迷服务。

八、政策更新

本政策对应当前离线版本。如后续增加账号、联网、广告、支付或其他数据处理，必须先更新政策和组件清单，并在需要时重新征求同意，才启用相应处理。重大变化将通过应用内明显提示告知。
