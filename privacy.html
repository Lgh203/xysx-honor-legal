《星语随心消消乐》隐私政策

更新及生效日期：2026年10月9日 · 版本 1.0.1 · 版本号 100
包名：com.match.xysx.honor · App ID：104594388
政策版本：2026-10-09-xysx-honor-v2

本政策说明兰溪市辰谷信息技术服务有限公司（以下简称“我们”）运营的《星语随心消消乐》荣耀联运版本如何处理信息。请在开始使用前分别阅读本政策与用户协议。我们不会预先勾选同意选项。

一、先阅读、再决定

应用首次启动或本政策发生涉及个人信息处理的重要变化时，将显著提示您阅读全文。在您同意新版政策之前，我们不启动荣耀联运及分析 SDK 的信息采集、登录、角色上报等服务；您可以阅读内置完整文本、拒绝并退出。旧离线版本的同意记录不代表您同意此次新增的联网、账号及联运处理。只有您同意后，并在触发登录等具体功能时，才进行相应处理。

二、玩法与本地信息

游戏提供本地消除玩法，进度、分数、设置以及本政策的同意记录保存在应用私有存储。游戏引擎在设备上使用图形、音频、屏幕、系统版本及语言等运行环境信息以完成绘制、输入和播放。当前不提供游戏存档云同步；荣耀登录本身不等于已有云存档。清除数据、卸载或设备损坏可能使本地进度丢失。

三、荣耀账号、实名与联运服务

本版本通过荣耀游戏联运 SDK 使用内含的荣耀账号能力。在同意本政策并发起登录后，SDK 处理账号标识（OpenID、UnionID）和登录凭据，以及实现账号登录、连接、安全校验所需的设备和应用信息。本游戏使用登录结果建立本次游戏会话，不在页面展示或日志中输出登录凭据，不主动索取手机号、通讯录或精确位置。

实名核验需要时，姓名、身份证号由您在荣耀服务界面提供并由荣耀处理；请在相关界面阅读专门提示。游戏根据 SDK 返回的核验及防沉迷状态提供相应服务，不使用本地游客状态代替实名核验。游戏会将联运要求的角色标识、角色等级、区服及关卡等游戏状态提交至荣耀，积分及关卡取自已保存的经典模式进度；没有存档时为本地初始状态，不代表实时每步分数或云存档；这些不表示游戏提供网络聊天或跨设备存档。

本版本没有广告投放、充值、付费道具或提现入口，不接入独立广告、支付 SDK，也不调用支付接口。SDK 可处理的设备标识符不等于本游戏已启用广告投放。游戏联运内公告、活动及服务更新由荣耀服务提供，以实际展示为准。

四、第三方组件与处理清单

荣耀游戏联运 SDK（包含荣耀账号能力）

版本：2.0.28.301。提供方：深圳荣耀软件技术有限公司。用途：账号登录、实名认证及防沉迷、连接与风险控制、联运服务与更新。时机：您同意后发起登录、进入游戏或触发相关服务时，由 SDK 按功能处理。

信息范围：账号标识及登录信息；设备型号、系统及 ROM 版本、语言、SIM 国家码和运营商；包名、版本、网络类型与 IP；OAID、UDID、AndroidID；应用使用、联运活动时间/类型及优惠券等服务信息。本游戏配置关闭可选头像及昵称申请，不主动索取或展示这些附加资料；实名信息由荣耀的核验功能按其提示处理。处理方式：SDK 端侧读取或由您主动提交，并向荣耀服务器传输功能所需的数据。

保存：账号登录信息的保留与删除随荣耀账号规则处理；荣耀声明实名信息保留一年，网络、安全及运行类数据保留三年。详情及行权方式请阅读 荣耀游戏联运 SDK 隐私声明；导出参数表所附原文为 《关于荣耀游戏联运与隐私的声明》。

荣耀分析 SDK（联运所需组件）

版本：1.0.6.301。提供方：深圳荣耀软件技术有限公司。用途：联运运行分析及安全保障；不是广告投放。时机：同意本政策之后，启动联运服务及产生相应运行事件时。信息范围：MagicOS/系统/ROM 版本及系统类型、OAID、UDID、应用包名、SDK 与客户端版本、应用随机标识符；网络方式/类型及传感器列表。处理方式：运营及安全字段向荣耀服务器传输，网络类型和传感器列表在端侧处理。荣耀声明服务器相关字段保存一年后删除，端侧上述字段不留存。详见 荣耀分析 SDK 隐私声明。分析组件包含安全通信及处理依赖 security-encrypt 1.2.5.306、security-ssl 1.2.5.312、enc-ha 8.3.0.104，用于其必要的数据保护和分析流程。

荣耀广告标识服务组件（非广告展示）

版本：ads-identifier 1.0.3.300。提供方：深圳荣耀软件技术有限公司。它是联运的官方依赖，用于在同意后向相应荣耀服务提供 OAID 标识符能力；没有广告展示接口或广告位。有关该组件的说明见 荣耀广告标识服务 SDK 隐私声明。

游戏还包含 Unity 游戏运行时、FMOD 音频组件和本地适配代码，用于游戏本体；我们未为这些本地运行组件启用广告、在线分析或账号接口。我们不出售您的个人信息。本版本不包含自行运营的在线聊天、交易或云存档服务。

五、权限与关联启动

以下为本版合并荣耀联运和分析 SDK 后声明的权限。声明权限不代表每次启动都启用对应服务；我们按具体功能、用户同意及系统要求使用，部分为系统普通权限或荣耀服务通信权限，不是联系人、相机等运行时权限申请。

  • 网络访问 INTERNET：在同意后用于荣耀登录、实名核验、联运及分析服务的必要连接。
  • 网络状态 ACCESS_NETWORK_STATE：检查网络是否可用与连接类型，供联运及分析服务使用；不是读取无线网络密码。
  • Wi-Fi 状态 ACCESS_WIFI_STATE：供分析依赖识别设备当前 Wi-Fi 连接状态；不读取 Wi-Fi 密码，也不提供本游戏的精确定位功能。
  • 前台服务 FOREGROUND_SERVICE：供 SDK 声明的必要前台服务能力使用，本游戏没有无关的持续后台采集功能。
  • 请求安装应用 REQUEST_INSTALL_PACKAGES：用于荣耀联运或账号服务需要更新时，下载更新并交由系统安装器安装。此权限不允许静默安装；系统需要您另行操作时，将依系统提示决定。
  • 荣耀服务专用权限：com.hihonor.gamecenter.service.provider.READ_PERMISSION 与 WRITE_PERMISSION、com.hihonor.gameassistant.permission.AGREE_READ_PROVIDER 与 AGREE_WRITE_PROVIDER 用于对应荣耀游戏服务及协议状态交互；com.hihonor.iap.core.permission.ACCESS_PURCHASE_SERVICE 为官方联运包内嵌支付组件的通信声明，本游戏没有商品、购买按钮或支付调用。

上述权限不代表申请相机、麦克风、通讯录、精确定位或外部存储权限。本游戏没有用于这些权限的自定义功能。荣耀服务在必要场景可能关联启动荣耀账号、游戏中心、游戏管家、应用市场或系统安装器，用于登录、联运浮层、下载或服务更新；不以无关目的关联启动其他应用。若具体荣耀服务另行提示权限，请按服务界面说明决定。

六、信息存储与保护

本地存档保留至您清除应用数据或卸载。登录凭据仅按登录所需使用，不作为公开资料写入日志或对外提供。荣耀处理的信息按照其声明在中国大陆境内存储，保存期限详见上方对应 SDK 说明。我们减少不必要字段和接口调用，使用应用私有存储；联网服务使用其提供的加密通信。公开政策页面不包含密码、签名证书或客户端密钥。

若您主动通过邮箱或电话联系我们，我们处理您提供的联系方式和问题描述以答复请求，并仅在完成该目的及必要记录所需期限内保留。请勿发来账号密码、登录令牌或与问题无关的身份证件。

七、您的权利、退出与注销

您可从游戏内“隐私 · 账号”入口查看全文、撤回本政策的同意并退出。撤回会清除本游戏的同意记录并停止此进程，下一次进入须重新决定；它不会自动删除游戏进度、注销您的荣耀账号或删除已经依法处理的信息。删除本机数据可在系统应用设置中清除数据。

如需查阅、复制、更正、删除与本游戏相关的信息或提出其他个人信息请求，请通过下方联系方式联系我们。我们进行必要且适度的核验，通常在十五个工作日内答复。涉及荣耀处理的信息，我们将按 SDK 行权渠道协助；您亦可在荣耀游戏中心的账户及游戏服务控制中管理个人信息、停止游戏服务，或通过荣耀声明提供的渠道请求处理。停止游戏服务与注销荣耀账号是不同操作，请先阅读对应提示。

八、未成年人

未成年人应在监护人指导下阅读本政策与相关服务说明，合理安排游戏时间。未满十四周岁的儿童在提供个人信息前应由监护人共同阅读并作出相应决定。荣耀实名与防沉迷服务按其核验结果执行，游戏收到防沉迷退出通知时退出服务。适龄标识、软著及发行材料以运营主体提供并核对的资料为准，当前测试版不凭空标注已取得的资质。
